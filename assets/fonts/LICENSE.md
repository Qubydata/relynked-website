# Font licences

The fonts in this folder are served from relynked.com itself so that no visitor's request goes to Google or any other third party. All of them are licensed under the SIL Open Font License, Version 1.1 (OFL), which allows use, embedding, redistribution and subsetting. The full licence text is at the end of this file. The files come from the Fontsource npm packages (version 5.3.0), which repackage the original open-source releases.

Notes:

- Only the latin and latin-ext subsets are included.
- Manrope and JetBrains Mono have no Naira sign. `naira-noto-sans-wght.woff2` and `naira-noto-sans-mono-wght.woff2` are Noto Sans and Noto Sans Mono cut down with fonttools to the single character U+20A6, and `fonts.css` declares them under the Manrope and JetBrains Mono family names so the sign still renders from a web font.
- Italic and bold styles that the pages never requested are not included.
